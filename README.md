# Goety Tuner · 调律师

首先这是一个ai写的模组，含人量可以说是没有了。  
这里先感谢astra叠和deepseek叠。    
随后我在这里说一下模组的设计思路：  
首先，这是一个能使用全部聚晶的boss，整合包的聚晶有多少用多少（猎奇的除外）。但不是随机的，我会在接下来讲。  
其次，boss的战斗节奏和音乐强相关，一阶段有铺垫高潮低谷期，二阶段仅铺垫和高潮期。不同期间烈度不同，鼓励玩家干的事不同（当然不是教玩家玩游戏，但有区分度嘛）。  
最后，boss美术虽然是astra叠和gpt叠做的，但还是有一些设计意图的（难道astra叠不是gpt叠了吗？不许说我叠）  
比如boss周身三个球代表攻击/防御/召唤法术，哪个大了代表它在释放什么。  
聚晶机制的补充：  
先在初始化部分，利用一些证据将聚晶分为攻击/防御/召唤/其他，其中攻击聚晶/召唤聚晶我设计了评分机制，高的打得概率更高。  
且有一个学习机制：追踪boss+聚晶造成的伤害进一步影响攻击聚晶的动态评分、根据召唤聚晶的一些性能表现影响召唤聚晶的动态评分。  
公式：评分=静态评分+学习系数*动态评分；学习系数随着释放次数上涨，也就是说，对于单个个体，越到后面越体现其“学习性”。  
当然，就放几个当然看不出来谁优谁劣，能学就有鬼了，但是随着进度进行，boss会越来越喜欢复读一个局部最优解，其实已经够麻烦了。  
当然我还是给了其他聚晶保底权重的，不可能真的超级复读启动。（你的太阳落山了…）   
1阶段会召唤，2阶段转阶段时清空召唤物并不再召唤。相应地，攻击欲望和频率都上涨了。   
音乐中会有“重音”（不是teto），在音乐条上有标，其实它和音乐本体没啥关系，但我觉得是必要的。重音时会用调律波纹聚晶的方式把大伙给推开（转阶段的时候也会），敌我不分（但调律波纹聚晶是分的）。还会伴随着其他类法术的释放。   
这个设计一方面是为了击退玩家，但另一方面，是推开自己的召唤物，防止出现空窗期玩家近身被揍的情况（不代表防止了就不会被揍）  
  
当然我们有喜闻乐见的仆从版：  
我提几个特殊机制，  
1、对于调律师一系列（尽管其他是滚木），强健会加到巫法强效上。  
2、你可以用聚晶/聚晶包等物品左/右键配置它 【不释放/优先释放这些聚晶】  
3、你可以用下界之星左/右键配置它 【是否只释放优先释放的聚晶】
